MEAL PLANNER - MISE-STYLE PWA

This is a standalone phone-friendly prototype. It stores your profile and plan locally in the browser.

Use:
1. Open index.html in a browser.
2. On iPhone Safari, use Share -> Add to Home Screen.

Features:
- 2000 kcal / 200g protein profile preloaded
- 4 meals/day
- 1 person
- Lidl/Asda
- £40-50 target
- Weekly generation
- Swap individual meals
- Recipe modal
- Consolidated shopping list
- Local persistence via localStorage

For a production version, connect an AI backend and a live supermarket-price/nutrition database.
