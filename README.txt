MEAL PLANNER UPGRADE

To publish on your existing GitHub Pages site:
1. Open https://github.com/kpulawski2/meal-planner
2. Upload the provided index.html, replacing the current index.html.
3. Upload the provided manifest.webmanifest, replacing the current manifest.webmanifest.
4. Commit changes and wait for GitHub Pages to publish.

This upgrade adds more planner settings (household size, 1/3/5/7 day plan length, meals/day, cooking time, priority, dietary preference, UK supermarket choices, custom instructions), pantry inventory, backup export/import, and preference toggles. Existing styling and PWA setup are retained.

Limitations: this is still a static front end. Recipe prices are estimates, no live supermarket price feeds or AI API is connected, and local browser data does not sync across devices. The current recipe library is small; plan generation is rule-based rather than AI-generated.
