# Simpler everyday layout

The main tabs remain Today, Plan, Diary, Shopping list and More. Secondary actions use labelled native disclosures, which support keyboard navigation and keep their open state during a render.

- Today leads with compact planned totals and meals. The full target breakdown opens from Planned totals. Weekly routine cards appear when a saved routine is due for shopping review or prep; the routine editor stays in More → Planning & cooking.
- Meal cards keep View recipe visible. Meal options contains Log eaten, Keep, Swap, household portions, cooked actions and Like/Dislike. Cooked/kept badges stay visible. Completed days still show their finished state.
- Plan uses a dropdown for any planned day, including week two. Edit plan opens the existing tailored request. Plan tools contains weekly choices, budget fitting, explanations, review and One day/All days.
- Diary keeps Add food, dated meals, calorie and macro totals visible. Diary options contains barcode scanning, copying, goals and the seven-day view. Nutrient detail opens below the meals; unknown/partial data retains its meaning. Add food also offers scanning.
- Recipes keeps search and a meal dropdown. Collections, cuisine, equipment, style and sorting live in Filters & sort. View and Save stay on each card; planning, feedback and source attribution live in Recipe options. The first 12 results appear initially; Show 12 more extends the list and search still covers every recipe.
- Shopping has one progress summary and one Copy list action. List tools contains filtering, printing, a detailed copy and clearing checks. Products & prices and the existing purchase review remain available.
- Settings uses plan-length and meal-count dropdowns rather than button arrays. Core budget, household and calorie/protein inputs remain visible. Meal choices, receipt prices and food/cooking settings open separately. The update status and Update my plan action remain outside collapsed panels.
- More shows Recipes, Favourites, Pantry and Settings. One-off meals and specialist tools live in Planning & cooking; Appearance and backup have their own disclosures.

This changes presentation, not saved meals, pantry quantities, prices, diary entries, planner checks or notifications. App shell/cache revision: v51.
